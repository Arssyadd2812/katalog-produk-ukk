# Web Katalog Produk - PT Indonesia Solusindo (UKK)

Aplikasi Web Katalog Produk berbasis Client-Server yang dibangun menggunakan Laravel 11, Tailwind CSS, dan MySQL.

## Fitur Aplikasi

| Fitur | User | Admin |
| --- | :---: | :---: |
| Login / Logout | v | v |
| Register Akun | v | - |
| Lihat Foto Produk | v | v |
| Tambah Komentar | v | v |
| Tambah Foto Produk | - | v |
| Edit Foto Produk | - | v |
| Hapus Foto Produk | - | v |

## Teknolgi yang Digunakan
- **Framework Backend/Frontend:** Laravel 11 + Blade
- **Styling:** Tailwind CSS (Laravel Breeze)
- **Database:** MySQL
